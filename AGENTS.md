# Working preferences

- Prefer the smallest working solution first.
- Before suggesting a multi-part or custom solution, check whether a one-line or built-in property solves it.
- Do not add extra controls, types, layout, or behavior unless the user specifically asks for them.
- Preserve the user’s existing UI and code choices unless a change is required for the requested result.
- Explain the simplest change first; offer more complex alternatives only if the simple change is inadequate.
