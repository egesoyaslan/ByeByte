# ByeByte

ByeByte helps users understand and manage storage occupied by files and folders.

## Language

**Kind**:
The descriptive type of a file, or Folder for a directory.
_Avoid_: Extension when referring to a descriptive file type.

**Size**:
The number of bytes captured by a scan for a file, or the scanned total for a folder. This is distinct from allocated space on disk.

**Where**:
The complete path identifying a selected file or folder, including its name.
_Avoid_: Containing folder when referring to the complete path.
